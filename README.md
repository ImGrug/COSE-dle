# COSEdle

COSEdle is a Wordle-inspired web game I created for friends about my friends.

I wanted to build something fun that our group could play together online, so I created a browser-based guessing game featuring computer science terms. The game automatically refreshes with new puzzles twice daily at noon and midnight, giving players new challenges throughout the day.

## Why I Made This

I created COSEdle as a personal project to learn more about web development while building something my friends would actually enjoy playing. The goal was to take an idea from concept to deployment and create a game that could be easily shared online.
